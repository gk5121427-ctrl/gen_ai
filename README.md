# 🤖 Gen AI Chatbot

A simple and fast conversational AI chatbot built with LangChain, Groq, and Streamlit.

Live Demo: `Coming Soon` (deploying on Streamlit Cloud)
GitHub: https://github.com/gk5121427-ctrl/gen_ai

### 🚀 Tech Stack
- **LLM:** Groq - `openai/gpt-oss-20b`
- **Framework:** LangChain (ChatGroq, SystemMessage, HumanMessage, AIMessage)
- **UI:** Streamlit
- **Language:** Python

### ✨ Features
- Conversational memory - bot remembers chat history
- Clean Streamlit Chat UI
- Super fast response with Groq inference
- Lightweight and easy to deploy
